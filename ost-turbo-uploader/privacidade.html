OST TURBO Uploader — Política de privacidade

Última atualização: 17 de novembro de 2026 · Privacy Policy (English summary at the end)

O que é

O OST TURBO Uploader é um programa particular, usado apenas pelo dono do canal do YouTube OST TURBO, para enviar ao próprio canal os vídeos que ele produz. Ele não é oferecido ao público.

Dados que o app acessa

O app usa a API de Dados do YouTube só com a permissão youtube.upload, para enviar vídeos (videos.insert) ao canal OST TURBO. Ele não lê comentários, inscritos, estatísticas nem dados de outras pessoas.

Armazenamento e compartilhamento

O único dado guardado é o token de acesso do Google, salvo no computador do dono do canal, e um registro local dos vídeos enviados. Nada é vendido, compartilhado ou enviado a terceiros.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.

Uso dos Serviços de API do YouTube

Este app usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Contato

Dúvidas: pelo e-mail de contato do canal OST TURBO no YouTube.

English summary

OST TURBO Uploader is a private tool used only by the owner of the OST TURBO YouTube channel to upload his own videos via the YouTube Data API (youtube.upload scope, videos.insert only). It does not access or store other users' data. The only stored data is the owner's OAuth token and a local upload log on his own computer; nothing is shared with third parties. Access can be revoked at myaccount.google.com/permissions. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
